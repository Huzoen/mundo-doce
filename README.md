# Mundo Doce — Loja de Cupcakes Gourmet 🧁

## 1. Apresentação do projeto

O **Mundo Doce** é um sistema web desenvolvido para uma loja de cupcakes gourmet. O objetivo é oferecer aos clientes uma experiência simples e intuitiva para visualizar os produtos, adicionar itens ao carrinho e realizar pedidos pela internet.

O projeto foi desenvolvido como parte da atividade acadêmica Projeto Integrador Transdisciplinar em Engenharia de Software II (PIT 2).

## 2. Objetivos

- Desenvolver uma loja virtual de cupcakes gourmet.
- Apresentar os produtos disponíveis em um catálogo.
- Permitir adicionar e remover produtos do carrinho.
- Calcular automaticamente o valor total da compra.
- Permitir que o cliente informe seus dados para realizar um pedido.
- Armazenar os pedidos no banco de dados Firestore.

## 3. Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e responsividade.
- **JavaScript:** funcionalidades e interações do sistema.
- **Firebase:** serviços de infraestrutura e integração.
- **Cloud Firestore:** armazenamento dos pedidos.
- **Firebase Hosting:** hospedagem da aplicação.

## 4. Funcionalidades

- Visualização do catálogo de cupcakes.
- Exibição de imagens e informações dos produtos.
- Adição de produtos ao carrinho.
- Alteração da quantidade de produtos.
- Remoção de produtos do carrinho.
- Cálculo automático do valor total.
- Formulário para preenchimento dos dados do cliente.
- Registro dos pedidos no Firestore.

## 6. Manual de utilização

1. Acesse o endereço da aplicação.
2. Visualize os cupcakes disponíveis no catálogo.
3. Escolha os produtos desejados.
4. Clique na opção para adicionar os produtos ao carrinho.
5. Confira os itens e as quantidades selecionadas.
6. Altere as quantidades ou remova produtos, se necessário.
7. Clique na opção de finalizar pedido.
8. Preencha os campos com nome, telefone e endereço.
9. Envie o pedido.
10. Aguarde a confirmação de que o pedido foi registrado.

## 7. Estrutura do projeto

- `index.html`: estrutura principal da aplicação.
- `style.css`: estilos visuais e responsividade.
- `script.js`: funcionalidades do catálogo, carrinho e pedidos.
- `firebase.js`: configuração e conexão com o Firebase.
- `images/`: imagens utilizadas nos produtos.
- `firebase.json`: configurações de hospedagem do Firebase.
- `.firebaserc`: identificação do projeto Firebase.

## 8. Banco de dados

O sistema utiliza o Cloud Firestore para armazenar os pedidos realizados pelos clientes.

Os registros são armazenados na coleção `pedidos`, contendo os dados informados pelo cliente e os produtos selecionados.
